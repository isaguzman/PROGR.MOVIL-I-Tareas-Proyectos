Tip Time - Código de solución
=================================

Código de solución para la aplicación Tip Time del curso [Android Basics with Compose](https://developer.android.com/courses/android-basics-compose/course).


Introducción
------------
La aplicación Tip Time contiene varios elementos de interfaz de usuario para calcular una propina, enseñando sobre la entrada del usuario y el Estado (State) en Compose.


Requisitos previos
--------------
* Experiencia con la sintaxis de Kotlin.
* Cómo crear y ejecutar un proyecto en Android Studio.


Primeros pasos
---------------
1. Instala Android Studio, si aún no lo tienes.
2. Descarga la muestra.
3. Importa la muestra en Android Studio.
4. Compila y ejecuta la muestra.
